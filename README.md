# ScrAPP

Mobile-first React + TypeScript marketplace prototype with a green-and-white theme.

## Run

```sh
npm install
npm run dev
```

Open the URL printed by Vite. Build with `npm run build`.

## Demo

Use **Explore demo** on the welcome screen and select Student, Company, or Homeowner. Switch roles in Profile to explore buying and selling. Students buy; companies sell; homeowners do both.

Browse/search/filter/save listings, view details, message sellers, create/edit/remove photo listings, place pickup or delivery orders, cancel or complete demo orders, and rate sellers. Activity persists in browser local storage.

Registration and Google sign-in are simulations. Login checks for a locally registered email; passwords are not stored or verified. No real authentication, payments, email, or delivery services are connected. Use fictional account details. Clear site storage to reset the demo.

Institutional emails accept .edu and .edu country suffixes for demonstration. Company registration excludes common personal domains; this is only illustrative and does not establish domain ownership.

Sample material photos are AI-generated illustrations stored locally in a six-tile photo sheet. Uploaded listing photos stay on the device. Online fonts fall back to system fonts.
